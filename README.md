# 💰 Expense Tracker

A Python-based expense tracking application for recording, managing, and analyzing personal expenses.

## 🚀 Features

- Add and manage expenses
- Categorize spending
- Calculate total expenses
- Analyze spending patterns
- Visualize expenses

## 🛠️ Tech Stack

- Python
- Pandas
- Matplotlib
- Streamlit
